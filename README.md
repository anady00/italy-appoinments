# Prenot@Mi Availability Watcher

سكريبت بيدخل على حسابك في prenotami.esteri.it، يفحص كل الخدمات المتاحة على صفحة
`/Services`، ويبعتلك إيميل لما يلاقي مواعيد جديدة متاحة (تاريخ أخضر/"Disponibile").

## خطوات التجهيز

### 1) اعمل ريبو جديد على GitHub
ارفع الملفات دي كلها (`check_availability.py`, `requirements.txt`,
`.github/workflows/check-availability.yml`) لريبو **خاص (Private)** — عشان بيانات
حسابك متبقاش ظاهرة لحد.

### 2) جهّز Gmail App Password
1. فعّل 2-Step Verification: https://myaccount.google.com/security
2. اعمل App Password: https://myaccount.google.com/apppasswords
3. احفظ الكود المكون من 16 حرف (هتحطه كـ Secret فقط، متكتبوش في أي مكان تاني)

### 3) ضيف الـ Secrets في الريبو
Settings → Secrets and variables → Actions → New repository secret:

| اسم الـ Secret        | القيمة                                   |
|------------------------|-------------------------------------------|
| `PRENOTAMI_USER`       | إيميل/يوزر تسجيل الدخول في prenotami       |
| `PRENOTAMI_PASS`       | باسورد حساب prenotami                      |
| `GMAIL_USER`           | إيميل الجيميل اللي هيبعت منه التنبيه       |
| `GMAIL_APP_PASSWORD`   | الكود الـ16 حرف اللي عملته في الخطوة 2     |
| `NOTIFY_EMAIL`         | (اختياري) الإيميل اللي عايز تستقبل عليه التنبيه، لو مختلف عن GMAIL_USER |

### 4) شغّل السكريبت يدويًا أول مرة (اختبار)
- روح على تبويب **Actions** في الريبو
- اختار workflow اسمه **Check Prenot@Mi Availability**
- دوس **Run workflow** (زرار يدوي)
- تابع اللوج (Logs) وشوف هل الـ login نجح ولا لأ

**لو الـ login فشل:**
افتح `.github/workflows/check-availability.yml` وشيل الكومنت (`#`) من سطر
`DEBUG: "1"`، شغّل الـ workflow تاني، بعدين حمّل الملفات من "Artifacts" (هتلاقي
screenshots وHTML لصفحة تسجيل الدخول الفعلية) وابعتهاليا/راجعها عشان نظبط أسماء
الحقول (selectors) في دالة `login()` بالسكريبت على شكل الصفحة الفعلي.

### 5) بعد ما الـ login يشتغل تمام
سيب الـ workflow يشتغل تلقائي كل 15 دقيقة (تقدر تغير الرقم في سطر `cron` بالملف).
أول مرة بيشتغل، هيحفظ حالة كل الخدمات في `state.json` من غير ما يبعت إيميل (عشان
معندوش "قبل" يقارن بيه). من الرن التاني وبعديها، أي خدمة تتغير من "مفيش مواعيد"
لـ "فيه مواعيد" هتبعتلك إيميل فورًا.

## ملحوظات مهمة

- **الأمان:** بيانات حسابك متتخزنش في الكود، بس في GitHub Secrets المشفرة. برضه
  خلّي الريبو **Private** كطبقة حماية إضافية.
- **حد GitHub Actions المجاني:** الحساب المجاني بيديك حوالي 2000 دقيقة تشغيل شهريًا
  للريبوهات الخاصة. تشغيل كل 15 دقيقة ~ 96 مرة يوميًا، كل مرة بتاخد دقيقة-دقيقتين،
  يعني ممكن تقرب من الحد لو الريبو خاص. لو حصل كده، وسّع الفترة لـ 20-30 دقيقة أو
  خلّي الريبو Public (بس التوصية تفضل Private).
- **selectors التقويم:** كتبت الكود يدوّر على كذا شكل محتمل لخلية "متاحة" (class
  زي `available`/`disponibile`، أو لون خلفية أخضر). لو مش لاقي مواعيد أبدًا حتى لو
  متأكد إن فيه، فعّل `DEBUG=1` وابعتلي الـ HTML بتاع صفحة التقويم عشان أظبط الشرط
  بالظبط على شكلها الحقيقي.
